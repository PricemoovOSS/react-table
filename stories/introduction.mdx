# @pricemoov-oss/react-table

React components that render large tables: only the rows and columns on screen are in the page, whatever the
size of the data.

```tsx
import { Table } from "@pricemoov-oss/react-table";
import "@pricemoov-oss/react-table/dist/style/index.css";

<Table id="prices" rows={rows} isVirtualized virtualizerProps={{ fixedRows: [0], fixedColumns: [0] }} />;
```

## How it works

- **The table does not move.** It stays in the window; scrolling changes which rows and columns are rendered,
  one whole row or column at a time. Headers and fixed items are always aligned.
- **Fixed items.** Rows fixed at the top and columns fixed on the left are simply rendered first. Rows fixed at
  the bottom and columns fixed on the right are taken out of the flow and stacked against their edge.
  A relief shows where the fixed items end.
- **Indexes.** `virtualizerProps` takes indexes in your data (`rows`). Opened sub rows shift what is on screen,
  not your indexes.
- **Everything is replaceable.** Cell content, group cell, sub-rows toggle and context menu are components you
  can provide; colors, reliefs and separators are CSS custom properties; sizes and thresholds are properties.
